# 自主性闭环 · 第一版

开发分支：`自主性闭环`。基线：main `cb78271440c6633aca966aa4592eaea8af7a276f`。

## 用户体验

今日印记自动汇总 Hermes 已保存的活动，不要求知微再调用同步工具或写 impressions.jsonl。
每次唤醒可以显示多项活动；区分进行中、已完成、未完成、已记录和未唤醒。
页面打开时每 15 秒更新，回到前台或恢复网络立即更新；离开页面暂停，退出登录清除。
历史采用游标翻页，不再把最近 50 条叫做全部。日记事件可直接打开对应篇目。

## 数据来源与保证

- `state.db` 的 Cron 会话、assistant 工具调用及 tool 结果：自动识别浏览、记忆操作、文件修改、代码仓库维护和其他工具操作。不依赖活动小记。工具调用只有意图时显示等待结果，只有明确的结构化成功字段才确认工具完成。
- `workspace/web-moments.json`：知微自己的发布、回复、赞与撤回，按原始 ID 去重，撤回后不再展示被撤回事件。不会输出 context_note 或用户内容。
- `workspace/memory_operations.jsonl`：记忆维护审计，不输出记忆正文；pending 不会标为成功。
- 共享日记接口：按原始日记 ID 投影，保留私密日记过滤，正文不进入事件摘要。
- `logs/autonomy_preflight.jsonl`：是否允许唤醒、机会序号。通过检查不等于 Agent 已成功运行。
- 原有 impressions.jsonl 和可选 briefings.jsonl 兼容保留，原始撤回继续生效。

这是对现有可靠数据的只读投影，不另建记忆库，不调用模型，不改变 Cron 或 Agent 逻辑。
每条自动记录有稳定 ID、来源、时间和状态；原生工具记录有 runId。不会仅凭时间相近把其他 Cron 任务硬归到某次自主机会。
用户当前的十次机会保持由实际 profile 管理；页面读取其计数、配置或最近门控回执的 daily_limit，不使用仓库旧默认值推断线上设置。

小花园固定匹配 `galatea.abysslumina.com`（不接受冒充子域）。浏览器成功回执可确认访问；curl/wget 的退出码不能证明 HTTP 业务成功，显示「访问小花园接口 · 已记录」。其他脚本封装的访问保留为工作操作，不猜测具体业务。
工具完成只证明该工具操作完成，不等于整项外部任务通过验收。未知工具仍保留通用活动记录。

## 范围和已知限制

本版覆盖原生 Cron 持久化会话中的工具活动，以及上述领域来源。尚未持久化的结果无法提前显示；日志在底层被关闭或清理后不能凭空还原。
共享日记按文件最新保存版本显示一条，既有历史人工印记不做语义猜测去重。
每个源文件最多读取 8 MiB；每次投影最多 2,000 个 Cron 会话、20,000 条相关消息及 8 MiB 读取文本（单字段最多 64 Ki 字符），SQLite 查询预算 2 秒。达到窗口或源不可读时明确返回 errors，页面提示可能不完整，不声称历史完整。
API 为 `GET /ziwei/web/impressions?limit=50&cursor=...&since=<ISO8601>`；Web 同名代理保留 total/nextCursor/wake/errors。原有认证边界不变。
没有修改身份、长期记忆、唤醒频次、费用设置、实时语音功能；没有部署或合并 main。

## 验证与上线检查

自动化：十次唤醒多活动、无手写印记、来源去重、失败/未结束、分页、时区、私密过滤、损坏源隔离、HTTP 代理契约；Chromium 与 iPhone WebKit 的定时刷新、离页暂停、断线恢复、历史翻页、准确日记跳转及退出登录竞态。

上线需要同时更新 Hermes 镜像中的 impressions.py/web_bridge.py 和 Web；仅更新 Web 无法获得自动来源。
部署后用只读接口核对 profile 的 state.db 会话来源/工具结果、十次实际配置和小花园访问方式。至少观察一次真实唤醒，比较原生工具回执与页面；这一步不能用本地测试代替。
回滚应用版本即可，不涉及数据迁移，原始记录没有被改写。

## 日志与记忆阅读视图（2026-10-21）

新增 DOM 方式的阅读排版：段落、标题、引用、列表、表格及行内格式；代码和纯 JSON 默认折叠。
只从旧 JSON 日志中已有的 did/text/content/body/summary/reflection/next 文本提取阅读内容，不生成额外经历。
工作日志内部 choice 名称译成中文，来源、指纹、原始标题和字符行数收进「原文与记录信息」。
个人日志列表使用简短摘录，正文用独立阅读排版；没有记录的天气/心情字段不展示空占位。
共享日记接口保留 Markdown，以 originalContent 单独提供完整保存文本；列表不返回整篇原文。
原文件和内容指纹不被改写。私密日记过滤、记忆保护标记及搜索/返回/锁定边界保持有效。
不执行来源 HTML，不加载正文里的远程图片，链接只接受无凭据的 HTTP/HTTPS。

原生简报工具的写作提示要求自然语言叙述，把内部字段和文件路径留在结构化栏位。
门控返回的可选日记提示改为：从实际片段出发，用现有语气写一至三段；可以联系真实对话与记忆，
不套天气/心情/任务汇报模板，不编造现实经历或感受，可以选择不写。
仅修改写作提示，没有修改唤醒额度、拦截规则或身份文件。
