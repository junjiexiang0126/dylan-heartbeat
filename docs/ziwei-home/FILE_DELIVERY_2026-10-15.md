## 问题及结果

旧回传只认最终回复里独立的 `MEDIA:/绝对路径` 行。截图所示“路径备份：.../workspace/outbox/给小语-20261015.txt”本身属于普通文字，仅有这种形式时不会进入附件清单；截图不能证明隐藏前的原始回复是否还含 MEDIA 行。Web 随后又会忽略同步异常，手动同步接口无条件报告成功；某条回复已有朗读音频时，前端还会把未送达文件的 MEDIA 提示一起隐藏。

现在兼容该次运行最终回复中明确给出的 outbox 路径和 Markdown/sandbox 文件链接。保留原 MEDIA 协议；普通路径/链接仅限 `HERMES_HOME/workspace/outbox`，不下载任意网址、不扫描目录、不从用户输入或工具输出猜测文件。文件必须实际存在并通过原有目录、所有权、类型、大小及符号链接检查。未找到文件、受限类型或读取失败会返回诊断；Web 按大小和 SHA256 核对后私有保存并关联到回复。

普通文件显示文件名、大小和下载操作的文件卡片。每条回复保存 complete/partial/failed/none/unavailable 接收状态，附件失败不再伪装为成功；失败消息可“重试接收附件”。重试只取该条 Web 请求绑定的原生运行，不能指定其他 run_id，不重新提交模型请求。已有朗读音频不再代表其他文件已送达。
