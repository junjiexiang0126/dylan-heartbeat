## 此次“连接失败”的证据与边界

2026-10-15 08:55:39–40（Asia/Bangkok），原生服务日志记录 DeepSeek `deepseek-flash` 返回 HTTP 503 / `service_unavailable_error` / `Service is too busy`，并在本次调用尝试后停止。同期 Web 请求被接受，Hermes 能力、会话、运行和事件接口有成功响应。这次失败在上游模型服务，并非凭据丢失或整个 Hermes 服务离线。

本轮只改聊天前端：定时重新读取既有连接状态；将消息中的失败提示与连接标识分开。末条失败的助手消息明确包含模型 API 503 时，提示上次模型服务暂不可用；没有这类明确内容时只提示上次回复失败，不猜测原因。不新增后端探测接口、不自动重发失败消息、不切换模型、不更换密钥、不重启 Hermes。外部模型是否恢复，仍需后续一次真实回复验证；界面修正不等于已修复 DeepSeek 的服务故障。
