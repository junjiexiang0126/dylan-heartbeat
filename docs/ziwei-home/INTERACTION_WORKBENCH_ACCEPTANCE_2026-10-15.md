# 交互与工作台收尾 — 2026-10-15

本轮整合 Web 782b99a 与知微的原生 186d4f9。服务仍是现有 ziwei-home-web-test (/ziwei_web) 和 ziwei-hermes-test (/hermes_native)，原有卷、记忆、Cron 计数、模型凭据均保留。

## 交付

- **受控脚本升级**：新增降权前 preflight_upgrade.py，由操作方部署变量精确选择已审核的新 SHA。仅允许从已知旧脚本升级至 186d4f9 的脚本；校验普通文件/所有权/硬链接/符号链接/哈希/语法，保存按旧 SHA 命名的只读备份，原子替换并写升级回执。重复启动幂等，不运行门控、不递增或重置机会数。没有赋予 Agent root 或 sudo，也不让 Agent 写升级标记。
- **朋友圈会话隔离**：继承知微的工具白名单，补上原生 skip_memory、skip_background_review、memory_manager=None 与实例级后处理回调禁止。普通聊天与 Cron 的记忆权限不变。缺少必要原生钩子时拒绝生效，不再只记日志继续运行。原生运行记录仍可能保存，不代表长期记忆提炼。
- **拍一拍**：双击聊天头像，或点击助手消息旁“拍一拍”；持久化为轻量事件，三秒限频、同编号幂等，通过原有任务队列通知知微。知微自主选择回应，可使用新 ziwei_poke 工具回拍。回拍写入原生自己的出站记录，经只读接口同步到真实聊天时间线。界面不会用一段普通文字冒充工具回拍。
- **朋友圈封面**：点击自己的封面选择图片，复用受保护图片上传并保存到服务器；刷新及其他已登录设备可读取。查看知微相册时保留默认封面，避免误改他的展示资料。
- **作者相册**：点击昵称或头像，仅展示该作者动态；有“全部动态”返回。点击互动消息可打开对应动态。
- **互动通知**：知微对用户动态点赞、回复用户动态/评论时生成持久通知，按回复真实可展示时间出现。底部朋友圈有未读红点；打开互动消息后按已展示最大编号标记已读，后来的通知不会被误吞。通知属于**站内通知**，关闭网页时继续保存，重新打开可见；本轮没有新增 iOS 系统推送权限或离线推送。
- **工作台只读预览**：设置→工作台；展示 Web/Hermes/Gateway 状态、Guardian 未核实状态、版本、审核脚本回执、六次机会计数、最近门控日志、任务状态、记忆文件保存时间、已有会话累计 Token/调用/记录费用，以及可主动查询的 DeepSeek 账户余额。无真实来源的日/月精确费用与服务器账单保持未知，不填0、不当作已结算金额；不新增执行/改配置/编辑记忆操作。

## 验收

1. 部署成功后刷新 PWA，双击知微头像或点消息动作，看到一条拍一拍，刷新仍在；重复请求编号不重复。知微只有实际调用 ziwei_poke 后才出现原生回拍。
2. 点击朋友圈封面选图，刷新保留；点击自己/知微头像或昵称，只看到对应作者。
3. 知微对你的动态实际点赞/回复，检查站内消息、底部红点；打开消息后红点消失。已有回复延迟规则继续生效。
4. 设置→工作台，检查真实版本、脚本回执、计数和任务。没有日/月账本、Guardian 证明或服务器账单时应明确待同步。

6. iPhone 双击手势、图片选择、键盘和 PWA 仍需用户真机验收。自动化夹具不算真实知微回复。
