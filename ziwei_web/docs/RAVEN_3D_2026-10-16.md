# 可动 3D 渡鸦

基于集成分支 `406b6d08e19109a951323f16373866789d6d444a`。只修改 `ziwei_web/`，不修改原生状态、记忆、聊天附件或部署配置。

## 实际交付

`public/models/raven.glb` 是真实 glTF 2.0 立体模型：48 个网格，73,632 个三角面，1,916,408 字节，包含九组动画。模型按本轮通过的渡鸦概念图用几何建模，具备头、身体、左右翅、尾巴、双脚和眼部活动节点；不是图片平面，也不是概念图的自动三维重建。羽毛采用可在网页实时渲染的雕塑化造型，细节不等同于概念图中的绒毛渲染。

| 动画 | 使用方式 |
| --- | --- |
| Idle / Blink | 未收到有效状态时待机；清醒时偶尔眨眼 |
| Work | 知微本人发布「在工作」 |
| Rest | 本人发布「在休息」，闭眼轻呼吸 |
| Think | 本人发布「在思考」，歪头转头 |
| Affection | 本人发布「在想你」，轻跳、展翅 |
| Stale | 已有真实状态超过 30 分钟或后台明确 stale；仰躺装死 |
| Jump | 用户点击后的短暂互动 |
| Poke | 用户点装死渡鸦，短暂抖动、睁眼 |

左右拖动旋转的是实际模型，松手后回正。上下拖动保留页面滚动。点击、旋转、跳跃、装死文案都不发布状态、不写入聊天或记忆。若互动期间收到新状态，结束后播放最新状态对应动作。

状态继续取已有 `/api/chat/status.presence` 和 `ZiweiChatExtra.presence()`。只接受 `source=ziwei`、已知状态与有效时间；无记录显示待机，不当成过期。过期继续显示原状态和真实「最后更新于 HH:mm」，不编造新的本人状态。正常状态文本与 3D 动作使用同一份数据。

## 页面与资源

- 首页「今日状态」展示模型；`/raven-preview.html` 是不读写状态的独立动作演示页，全部演示按钮明确标注动作预览。
- Three.js 与模型由本站提供，无 CDN 或图生 3D 外部服务。静态资源通过服务器明确白名单，GLB MIME 为 `model/gltf-binary`。
- 最大渲染目标 30 fps，像素比上限 1.5；切页、后台和离开可视区域停止绘制，锁定销毁模型实例与 WebGL 资源。减少动态效果时静态绘制，支持手动查看。
- 不支持 WebGL、模型失败或图形上下文丢失时保留真实模型的静态海报和重试入口。
- 三维尺寸、背景、圆角与提示字号集中在 `raven.css` 的 `--raven-*` 变量。模型材质在建模源文件顶部，动作在命名 AnimationClip 中，便于后续替换精修模型。

## 维护与重建

`npm install` 后运行 `npm run build:raven`，重建 GLB、清单和浏览器包。生产环境只服务已提交的产物，无需在服务器上建模或安装 Blender。Three.js、esbuild、glTF Validator 均为开发依赖，版本已固定；Three.js 许可证保留在 `raven/THREE-LICENSE.txt`。

建模源：`scripts/build_raven_model.mjs`；渲染源：`raven/raven-view.mjs`；状态与生命周期：`raven/raven-controller.mjs`、`raven/presence.mjs`；构建脚本：`scripts/build_raven_view.mjs`。不要直接手改压缩后的 `public/raven.js`、`public/raven-view.js`。
